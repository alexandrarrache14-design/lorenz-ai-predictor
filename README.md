# 🦋 Lorenz AI Predictor

Proyecto de **Estructuras de Datos - Ingeniería en Inteligencia Artificial (UIS)**.
**Estudiantes:** Rafael Alejandro Salamanca Tapias & Pathy Alexandra Rache Guaman.

## ¿De qué trata este proyecto?
Evaluamos si tres modelos de redes neuronales (**FFN**, **RNN** y **LSTM**) pueden aprender la trayectoria caótica del **Atractor de Lorenz** generado mediante el método numérico **Runge-Kutta 4 (RK4)** y predecir sus posiciones futuras $(X, Y, Z)$.

## Cómo ejecutar el proyecto
1. Descargar el repositorio en formato ZIP y abrir la carpeta en Visual Studio Code.
2. Instalar las librerías necesarias en la terminal:
   `pip install -r requirements.txt`
3. Ejecutar la aplicación web:
   `python -m streamlit run app.py`
